## Before Opening an Issue
1. Check the [FAQ](README.md#faq)
2. Search [existing issues](https://github.com/akaanakbaik/libsignal/issues)
3. Verify you're using a [supported Node.js version](README.md#compatibility-matrix)
4. Provide a minimal reproducible example
